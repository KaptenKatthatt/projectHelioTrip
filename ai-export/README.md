# AI Export Package

This folder contains a reusable AI setup package extracted from this repository.

## Folder layout

- `template/` contains instruction and rule files to copy into a new repository.
- `quality-gates/` contains reference configuration and verification guidance.
- `manifest.json` is generated by the export script and tracks synced files.

## Commands

- `npm run ai:export` updates this package from source files.
- `npm run ai:export:check` verifies this package is in sync.

## Install in another project

1. Copy everything under `ai-export/template/` to the root of the target repo.
2. Read `template/context/AGENTS_CONTEXT.md` and keep the read order intact.
3. Copy `quality-gates/source-reference/` files as a baseline where applicable.
4. Update project-specific assumptions listed in `ai-export/quality-gates/README.md`.

## One-command install helpers

- Bash:
  - `./ai-export/install.sh /path/to/new-project`
- PowerShell:
  - `powershell -ExecutionPolicy Bypass -File .\\ai-export\\install.ps1 -TargetProjectPath C:\\code\\new-project`

These scripts copy `template/` into the target repo root and place quality-gate docs under `target/ai-export/`.

## Prompt template for your AI in the new project

Use this prompt in the target repository:

`Open and apply the AI setup from ./ai-export (or from root files if already copied). Follow AGENTS read order exactly: context/AGENTS_CONTEXT.md -> context/AGENT_REFERENCE.md -> context/DESIGN_SYSTEM.md -> .cursor/rules/*.mdc -> .github/copilot-instructions.md. Then implement required repository-specific customizations from CUSTOMIZE_BEFORE_USE.md, and verify with npx tsc --noEmit and npm run lint.`

## Recommended workflow

- Keep this package versioned in git.
- Run `npm run ai:export` after changing rules/instructions.
- Run `npm run ai:export:check` in CI to detect drift.
